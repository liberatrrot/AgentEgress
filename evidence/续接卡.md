## 铁律（违反即前功尽弃）

```
❶ **标注阶段只读代码，不运行任何 detector**
   —— 看到的第一个数字会锚定判断（第 5–7 次"检查写错"的教训）

❷ **不把结构层结论外推到 capability 层**
   —— 结构 relation 漏掉 ≠ capability verdict 必然漏掉

❸ **reachable_chain = 0 ≠ capability absent**
   —— 它等于"能力存在但链路未被证实"

❹ **GT 必须先冻结，再跑 detector**
   —— 顺序反了就是循环校准
```

```

⑤ 未发现新的、无法解释的 capability taxonomy
```
